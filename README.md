
# Лабораторная работа №8: SSL/TLS Шифрование

## Тема: Разработка клиент-серверного приложения с использованием SSL/TLS шифрования

---

### Цель работы

Приобрести практические навыки защиты данных в сетевых приложениях путем реализации SSL/TLS шифрования для клиент-серверного взаимодействия на основе сокетов.

### Требования к окружению

*   **Python 3.x**
*   **OpenSSL** (обычно предустановлен в Linux/macOS, в Windows поставляется с Git Bash).

### Инструкция по установке и запуску

#### 1. Генерация SSL-сертификата

Для работы приложения необходимы самоподписанный сертификат и приватный ключ. Чтобы их сгенерировать, выполните в терминале в корневой папке проекта следующую команду:

```bash
openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -sha256 -days 365 -nodes
```

> **Важно:** Во время генерации, на запрос `Common Name (e.g. server FQDN or YOUR name) []:` необходимо ввести **`localhost`**, чтобы избежать ошибки несоответствия имени хоста. На остальные вопросы можно нажимать Enter.

В результате будут созданы файлы `key.pem` и `cert.pem`.

#### 2. Запуск сервера

Откройте терминал, перейдите в папку проекта и выполните команду:

```bash
python secure_server.py
```

Сервер будет запущен и начнет прослушивать порт `8443`.

#### 3. Запуск клиента

Откройте **второй** терминал, перейдите в папку проекта и выполните команду:

```bash
python secure_client.py
```

Клиент подключится к серверу, отправит сообщение "Это секретное сообщение!" и получит его обратно в качестве эхо-ответа.

### Результат работы

На скриншоте ниже продемонстрирован процесс работы:
*   **Справа:** Генерация сертификата с указанием `localhost` в поле `Common Name` и успешный запуск сервера.
*   **Слева:** Первая неудачная попытка запуска клиента (до исправления сертификата), которая приводит к ошибке `Hostname mismatch`, и вторая, **успешная** попытка после перегенерации сертификата.
