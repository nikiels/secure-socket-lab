# Лабораторная работа №2: SSL/TLS Шифрование

Отчет по лабораторной работе №2 по дисциплине «Программное обеспечение компьютерных сетей».

**Тема:** «Разработка клиент-серверного приложения с SSL/TLS шифрованием»

---

## Описание проекта

Проект представляет собой простое клиент-серверное приложение (эхо-сервер), взаимодействие между компонентами которого защищено с помощью криптографического протокола TLS. Данные, передаваемые между клиентом и сервером, шифруются, что обеспечивает их конфиденциальность и целостность.

## Функциональность

*   **Сервер (`secure_server.py`):**
    *   Создает TCP-сокет на порту `8443`.
    *   Загружает SSL-сертификат и приватный ключ для установки защищенного соединения.
    *   Ожидает подключения клиента, "оборачивая" стандартный сокет в SSL/TLS.
    *   Принимает зашифрованное сообщение от клиента, расшифровывает его и выводит в консоль.
    *   Отправляет полученное сообщение обратно клиенту в зашифрованном виде (эхо).

*   **Клиент (`secure_client.py`):**
    *   Подключается к серверу по адресу `localhost:8443`.
    *   Проверяет сертификат сервера, чтобы убедиться в его подлинности (сравнивает `Common Name` в сертификате с хостом `localhost`).
    *   Устанавливает зашифрованное соединение.
    *   Отправляет тестовое сообщение серверу.
    *   Получает эхо-ответ, расшифровывает его и выводит в консоль.

## Состав проекта

*   `secure_server.py` — исходный код сервера.
*   `secure_client.py` — исходный код клиента.
*   `.gitignore` — файл, указывающий Git игнорировать служебные и секретные файлы.

*Примечание: файлы сертификата (`cert.pem`) и ключа (`key.pem`) намеренно не включены в репозиторий из соображений безопасности. Для запуска проекта их необходимо сгенерировать локально.*
